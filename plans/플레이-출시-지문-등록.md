- 11-25 자동 제작이 처음 만든 고정 키 (별칭 dongne, RSA 2048, 2054년까지).
- 저장소에는 잠근 파일 `tool/upload.jks.enc` 만 있음. 여는 비밀번호는 깃허브 비밀 `ANDROID_KEY_PASS` (대표님이 넣은 값, 저장소에 없음).
- 지금까지 받은 설치 파일(APK)도 이 키로 서명돼 있어, 파이어베이스에 이미 이 지문을 등록해 둠.

## 출시용 AAB
- 올리는 글 제목에 `[출시]` 가 있으면 자동 제작이 서명된 AAB를 만들어 깃허브 릴리스 `store` 에 올림.
- 받는 곳: https://github.com/90mkr/df-uridongne/releases/download/store/udongkok.aab
- 다음에 다시 올릴 때는 pubspec.yaml 의 `+숫자`(버전 코드)를 1씩 올려야 플레이가 받음.

## 콘솔에 올린 뒤 할 일 (구글이 다시 서명하는 「앱 서명 키」 지문)
1. 플레이 콘솔 → 우동콕 → 테스트 및 출시 → 설정 → 앱 무결성 → 「Play 앱 서명」 → 「앱 서명 키 인증서」의 SHA-1·SHA-256 복사
2. 파이어베이스(kokple) → 프로젝트 설정 → 내 앱 kr.designfeel.dongne → 「디지털 지문 추가」에 SHA-1, SHA-256 두 개 추가 (기존 업로드 키 지문은 그대로 둠)
3. 카카오 개발자 → 내 애플리케이션 → 앱 → 플랫폼 → Android → 키 해시에 「앱 서명 키 SHA-1」을 바꾼 값 추가 (본부에 SHA-1 알려 주면 바꿔 드림). 업로드 키 해시도 같이 넣어 둠
4. 네이버 지도(네이버 클라우드 플랫폼 Maps): 지문이 아니라 패키지 이름으로 확인 → kr.designfeel.dongne 이 등록돼 있는지만 확인
