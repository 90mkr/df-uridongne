# 본부 → 반려동물 방: 사진 보관 기준 (대표님 11-26 결정)

## 반려동물 소통방은 단지 게시판과 **완전히 별개** (대표님 11-26)
- 「우리 단지 이야기」(단지·동네 소식·나눔·분실물)와 섞지 않음. 반려동물 테마 안에 따로 있는 **개·고양이 이야기 방**.
- 글 칸도 따로 (예: dn_pet_posts) — 단지 게시판 글 목록·알림·포털에 섞여 나오지 않게.
- 범위는 단지가 아니라 **동네(구) 단위** 이상이 좋음 (반려인은 단지 안에 몇 명 안 됨). 갈래 예: 강아지 · 고양이 · 궁금해요 · 자랑해요 · 산책 친구 · 실종·보호.

## 요기콕 반려동물 테마
1. **우리 아이 수첩**: 증명사진처럼 **아이 한 장만** (줄여서 저장, 로그인 저장 `core/mydata.dart`). 앨범처럼 여러 장 올리기는 **안 함**.
   - 사진 한 장은 작게(예: 긴 쪽 480px 안팎) 줄여 JSON 400KB 안에 들어가게. 더 크게 필요하면 본부에 저장소(Storage) 요청.
2. **소통방 사진**: 올릴 때 휴대폰에서 줄여 올림(게시판과 같은 방식 — 본문 960 · 목록 320, 원본은 서버로 보내지 않음, 촬영 위치 정보 빠짐).
   - **90일 뒤 사진 자동 삭제**, 글은 남기고 「보관 기간이 지난 사진이에요」 표시.
   - 올리는 화면에 작게 「사진은 90일 뒤 삭제돼요」 안내.
   - 실종·임시보호 글: 「찾았어요」 후 30일 뒤 글·사진 삭제 (안 찾은 글은 유지).
   - 올린 사람은 언제든 직접 삭제, 탈퇴하면 그 사람 사진 모두 삭제.
   - 사진은 글 칸(Firestore)에 넣지 말고 사진 저장소(Storage)로 — 본부가 저장소·규칙·자동 삭제(서버 작업) 마련.
3. 이용자 휴대폰 사진첩의 원본은 앱이 건드리지 않음.
