# 복권 방 요청: 토요일 밤 당첨번호 갱신

- 무엇: `.github/workflows/` 에 토요일 밤·일요일 아침에 `collector/features/lotto.py` 만 돌려 `web/data/lotto/` 를 저장하고 미리보기(data/)에 올리는 일정
  - 토요일 21시 20분 (한국) `cron: '20 12 * * 6'`
  - 일요일 오전 9시 7분 (한국, 토요일에 막혔을 때 다시) `cron: '7 0 * * 0'`
  - 비밀: `KAKAO_REST_KEY` (판매점 목록용, 없어도 당첨번호는 됨)
  - 끝나면 「모은 자료 저장」과 같은 방식으로 커밋 → 미리보기 게시 (앱 자체를 다시 만들 필요는 없음, data/ 만 바뀌면 됨)
- 왜: 지금은 자료 모으기가 월요일 새벽 한 번뿐이라, 토요일 저녁 8시 35분 추첨 결과가 월요일 새벽까지 안 보임.
  복권 화면은 「이번 주 당첨번호」가 핵심이라 토요일 밤에 바로 떠야 함.
- 참고: 1회 실행 2~3분 (새 회차 1개만 받음). 동행복권이 막혀도 공개 모음(github smok95/lotto)으로 채움.
- 급한 정도: 높음 (이번 주 토요일 11월 28일 1252회 전에 되면 좋음)
- 작업판 버전: lotto 0.1.0
