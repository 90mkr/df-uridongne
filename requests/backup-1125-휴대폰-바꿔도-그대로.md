# 대표님 요청: 휴대폰을 바꿔도 앱을 그대로 (회원 전체 백업·복원)

- 누가: 대표님 (11-25) — 기념일 화면의 「알림은 이 휴대폰에만 저장돼요. 휴대폰을 바꾸면 다시 등록해 주세요.」 문구를 보고 「무책임하게 다 날리면 안 된다」고 지적. 콕플·시안 방이 받아 적음.
- 급한지: 높음 (대표님 직접 지시)

## 대표님 말씀 그대로의 요구

특정 기능만 백업하는 것이 아니라, 그 회원이 이 앱에서 해 둔 **모든 것**을 한꺼번에 보관해 두었다가 새 휴대폰에서도 **이전 상태 그대로** 바로 쓰게 한다. (예: 급식 볼 학교를 골라 둔 것까지)
로그인하면 원래대로 돌아오거나, 「불러오시겠습니까?」를 묻고 다시 올리는 방식. 비회원까지 챙길 필요는 없다고 보심.

## 무엇을 옮기나

- 전부: 고른 단지(`complex`, `lib/core/data.dart`)와 `prefGet/prefSet` 으로 저장하는 모든 칸
  - 지금 있는 것: 기념일(`anniv.list`), 알람 목록(`alarm.list`), 우리 아이 학교·급식(`school.mine`, `school.alarm.*`), 자주 타는 버스·노선(`bus.pinned`, `bus.favRoutes`), 복권 저장 번호(`lotto.mine`), 홈 카드 배치·숨김(`home.order`, `home.hide`, `home.on`, `home.hideTools`), 택배·주소(`postcode.*`), 기름 종류·반경(`gas.*`), 충전 플러그·타이머(`charger.*`), 룰렛 메뉴(`roulette.foods`), 날씨 알림(`weather.alarm*`), 길안내 앱(`core.navApp`)
  - 앞으로 생길 기능 칸도 따로 손대지 않아도 자동으로 들어가게 (공통 저장 칸 한 곳에서 처리)
- 빼는 것: 주차한 자리 위치·사진(`parking.car`, `parking.carPhoto`) — 화면에 「서버로 보내지 않아요」라고 약속했고, 출차하면 지워지는 임시 자료
- 비회원: 하지 않음

## 제안하는 방식

1. 공통 저장 칸(`prefSet`, 단지 저장)에서 값이 바뀌면, 로그인 상태일 때 파이어베이스 `dn_backup/{uid}` 문서 하나에 모아 올린다 (몇 초 모아서 한 번에, 저장 시각 같이).
2. 새 휴대폰에서 로그인했을 때 계정에 보관본이 있고 이 휴대폰 자료가 비어 있거나 더 오래됐으면 묻는다:
   「이전 휴대폰에서 쓰던 설정이 있어요 (11월 24일 저장). 그대로 불러올까요?」 [불러오기] [새로 시작]
3. 불러온 뒤 예약 알림을 모두 다시 건다 — 기념일(`rescheduleAnnivs`), 학교·날씨 등 예약 알림 전부.
   알람은 시계 앱 알람이라 자동으로 못 거니, 알람 목록에 「이 휴대폰 시계에 다시 넣기」 버튼.
4. 쓰기 규칙: `dn_backup/{uid}` 는 본인만 읽고 쓰기 (대표님 파이어베이스 규칙 게시 필요).
5. 개인정보처리방침(`web/policy/`)에 「로그인 회원의 앱 설정(기념일 이름 등)을 보관해 휴대폰을 바꿀 때 되살림, 백업 지우기 가능」 한 줄.
6. 「내 정보」에 「백업: 11월 25일 14:02 보관됨 · 지금 보관 · 보관본 지우기」 한 줄.
7. 안내 문구 바꾸기: 기념일·알람·학교 등의 「이 휴대폰에만 저장돼요」 →
   - 로그인했을 때: 「휴대폰을 바꿔도 로그인하면 그대로 돌아와요」
   - 로그인 안 했을 때: 「로그인하면 휴대폰을 바꿔도 그대로 돌아와요」 + [로그인] 버튼
   - (주차 위치·사진 문구는 그대로)
   - 기능 방 화면의 문구는 각 방에 알리거나, 공통 문구 부품으로 바꿔 달라고 요청

## 참고

- 안드로이드 기본 백업(구글 계정)은 보조일 뿐 — 설치 파일로 깐 앱은 되살리기가 잘 안 되고, 휴대폰 백업 설정에 따라 다름.
- 작업판 버전: core 0.3.0, anniv(본부 소관)
