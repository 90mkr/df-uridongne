# 반려동물 방 → 본부: 추천 영상에 필요한 공통 세 가지 (대표님 11-26)

반려동물 0.7.0 「주제별 추천 영상」을 올렸습니다 (`lib/features/pet/videos.dart`, 수집 `collector/features/pet.py` → `web/data/pet/videos.json`).
지금은 영상을 누르면 앱 안 브라우저 창(유튜브 모바일 화면)으로 엽니다. 아래 세 가지가 되면 대표님 지시대로 마무리됩니다.

## 1. 유튜브 공식 플레이어 패키지 (pubspec.yaml)
- `youtube_player_iframe` 추가 부탁드립니다 (유튜브 공식 IFrame 플레이어를 앱 안에 띄움 — 영상 받기·저장 없음, 광고·조회수는 원래 채널).
- 넣어 주시면 반려동물 방이 `videos.dart` 의 `playVideo()` 한 곳만 바꿔 앱 안 재생 화면으로 바꿉니다. 퍼가기 막힌 영상은 지금처럼 「유튜브에서 보기」.
- 다른 기능(예: 동네 소식 영상)도 쓸 수 있게 공용으로 두셔도 좋습니다.

## 2. 하루 한 번 모으기 (build.yml)
- 지금 반려동물 수집은 월요일 전체 실행·수동 실행 때만 돕니다. 영상은 하루 한 번 새로 모아야 합니다.
- `40 22,3,9 * * *` 일정의 `FEATURES` 에 `pet` 을 더해 주세요 (예: `gas,events,pet`).
- 무겁지 않습니다: `pet.py` 는 같이 갈 곳(관광공사)을 **6일 안에 받았으면 건너뛰고** 영상만 모읍니다 (채널 RSS 3개 + 새 영상 퍼가기 확인 몇 번).

## 3. (선택) YOUTUBE_KEY
- 채널 RSS 는 채널마다 최근 15개만 줘서, 「노견 돌보기」처럼 오래된 좋은 영상이 있는 주제는 비어 보일 수 있습니다.
- 유튜브 Data API v3 열쇠(무료, 하루 1만 단위)가 있으면 `pet.py` 가 **하루 한 번만** 채널 안에서 주제별로 찾아 묶음을 채웁니다 (하루 약 2,300 단위).
- 열쇠는 대표님이 구글 클라우드 콘솔(파이어베이스 프로젝트)에서 「YouTube Data API v3」 사용 → API 키 만들기 → 깃허브 비밀 `YOUTUBE_KEY` 로 넣으시면 됩니다.
- 본부는 build.yml 「기능별 자료 모으기」 env 에 `YOUTUBE_KEY: ${{ secrets.YOUTUBE_KEY }}` 한 줄만 더해 주세요. 열쇠가 없으면 RSS 만으로 돕니다.

## 4. 화면 사진 장면 (.github/shot/shot.py)
- `pethome` 장면에 이어서: 반려동물 첫 화면을 아래로 밀어 「주제별 추천 영상」 띠 찍기 → 「전체 보기」 눌러 추천 영상 화면 찍기.
- 태블릿(1180×820)에도 같은 장면 하나 (예: `("탭반려", 1180, 820, pethome)`).
- 지금 사진으로는 휴대폰 첫 화면 아래 끝에 띠 윗부분만 보입니다.
