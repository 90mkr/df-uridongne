# 반려동물 방 → 본부(게시판 담당): 멍냥 소통방이 dn_posts 를 함께 씁니다 (대표님 11-26 「빨리 진행」)

반려동물 0.8.0 「우리 구 멍냥 소통방」(`lib/features/pet/talk.dart`)을 올렸습니다. 규칙은 **바꾸지 않고** 지금 게시판 규칙 그대로 씁니다.

## 어떻게 저장하나
- 컬렉션: `dn_posts` (댓글 `cm`, 신고 `dn_post_reports`) — 게시판과 같음
- `cid = 'p_<구 id>'` (구 id = 단지 `areaId` 의 `_` 앞부분) → 단지 게시판(단지 id)·동네 게시판(`a_…`)과 섞이지 않음
- `area` = 단지의 `areaId` (글 아래 동 이름 표시용)
- `cat` 은 규칙에 있는 값으로 말머리를 나타냄: free 자랑·수다 / news 질문 / rec 병원·가게 후기 / share 나눔 / lost 실종·목격
- `name` = 「첫 아이 이름 + 네」(예: 초코네), 아이가 없으면 계정 이름
- 스티커 댓글: 댓글 본문이 `:emo:c_lol:` 같은 꼴 → 앱이 냥이·멍이 스티커 그림으로 보여 줌

## 부탁
1. 관리자 게시판 관리 화면에 `cid` 가 `p_` 로 시작하는 글도 「반려동물 소통방」으로 보이게 해 주세요 (신고 처리·삭제).
2. 「내 글에 댓글」 알림이 `cid` 를 단지 id 로만 가정한다면 `p_` 글도 알림이 가게 맞춰 주세요.
3. 게시판 쪽에서 `dn_posts` 필드·규칙을 바꿀 때는 반려동물 방에도 알려 주세요.
4. 나중에 말머리를 늘리려면 규칙의 `cat in [...]` 에 `pet_` 값을 더해 주시면 반려동물 방이 옮기겠습니다 (지금은 급하지 않음).
