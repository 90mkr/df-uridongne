# 단지 홈 두 단계 배치 — 큰 카드 + 아이콘 가로 줄 (대표님 11-26, 본부 방 요청)

## 왜
- 지금은 고른 칸이 한 줄에 하나씩(큰 카드) 쌓여, 많이 고를수록 홈이 끝없이 길어짐.
- 중요한 것은 큰 카드, 덜 중요한 것은 아이콘만 모아 한 줄 가로 스크롤 (은행·토스 첫 화면 구조).

## 만들 것
1. **홈 = 위 큰 카드 + 아래 아이콘 줄**
   - 큰 카드: 지금처럼 한 줄에 하나 (살아 있는 정보가 보이는 카드).
   - 아이콘 줄: 3D 아이콘 + 짧은 이름만, 한 줄 가로 스크롤. 휴대폰에서 4개 반이 보이게 해 마지막 아이콘이 잘려 보이도록(옆으로 더 있다는 신호). 맨 끝에 「전체 보기」→ 생활 도구.
2. **기본값은 앱이 정함** (이용자가 손대지 않아도 되게)
   - 기능 등록부에 `homeSize: big | icon` 기본값 추가. 오늘 바뀌는 정보가 있는 것(날씨·버스·반려동물 산책·분리수거 날·주유소 최저가 등)만 big, 나머지(우편번호·로또·알람 등)는 icon.
   - 큰 카드 기본 3~4장.
3. **편집 화면은 두 칸만**
   - 「크게 보기」 / 「아이콘으로」 두 묶음. 각 줄에 위·아래 화살표 하나로 묶음 사이 이동(한 번 누르기). 끌어서 옮기기는 덤.
   - 묶음 안 순서 바꾸기는 지금 방식 유지.
4. **첫 화면에서 바로 바꾸기**
   - 아이콘 꾹 누르기 → 「크게 보기로 올리기」, 큰 카드 꾹 누르기 → 「아이콘으로 내리기」. 편집 화면에 들어가지 않아도 됨.
5. **옮겨 주기**: 지금 이용자가 켜 둔 칸·순서는 그대로 살리고, 각 칸은 2번 기본값으로 큰 카드/아이콘에 나눠 배치.

## 지킬 것
- 아이콘 줄 칸이 없는 기능(아이콘 그림 없음)은 지금 쓰는 아이콘으로 임시 표시.
- 휴대폰·작은 휴대폰·태블릿 화면 사진으로 확인([화면]), 아이콘 줄이 잘려 보이는지·큰 카드 개수 확인.
- 반려동물 「오늘의 반려 생활」 홈 배너는 big 기본(지금 스위치 동작 유지).


## 본부 처리 (11-26)
- 홈 = 위 큰 카드(크게 보기) + 아래 「생활 바로가기」 아이콘 한 줄(가로, 폭/4.5 → 휴대폰 4개 반·태블릿 7개 반, 끝에 「전체 보기」→생활 도구).
- 기본 크기: registry.dart `kHomeBig` = f:bus · m:gas · r:trash · m:pet (+ 늘 큰 today). 나머지는 아이콘. 홈 칸이 없는 기능은 i:<기능> 아이콘만.
- 편집: 「크게 보기」/「아이콘으로」 두 묶음, ↑↓ 한 번으로 이동, 묶음 안은 꾹 눌러 순서, ⊖/⊕ 유지. 첫 화면 꾹 누르기 → 올리기/내리기·홈에서 빼기·홈 편집.
- 이용자 순서·꺼 둔 칸 그대로(home.order/home.hide), 크기는 home.size 에 따로. 한 줄 카드(r:)는 이제 처음부터 보임(대부분 아이콘 줄).
- 화면 확인: 폰·작은 폰·태블릿.
