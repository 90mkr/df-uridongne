# 깃허브 비밀에 DATA_GO_KR_KEY 가 없음 (급함 — 약국·주차장·충전소 등 공공데이터 기능 모두 영향)

- 21:17 수동 실행(#36) 기록: 「주차장: DATA_GO_KR_KEY 가 없어 건너뜀」, 「약국: 공공데이터 열쇠가 없어 건너뜀」, 충전소도 같음.
- 저장소 Settings › Secrets › Actions 에는 지금 KAKAO_REST_KEY, OPINET_KEY 두 개만 있음.
- 열쇠값 넣기는 김부장이 할 수 없어 대표님께 안내함 (공공데이터포털 마이페이지 › 인증키 발급현황 › 일반 인증키 → 깃허브 비밀 DATA_GO_KR_KEY).
- 함께: collect 줄에서 대기 중인 수동 실행이 하나만 남고 나머지는 취소됨(#37 주차장만 실행이 #39에 밀려 취소). 대기 실행끼리도 밀어내므로, 동시에 여러 방이 누르면 앞의 것이 사라짐 — 참고.
- 작업판: 주차장 0.1.0
