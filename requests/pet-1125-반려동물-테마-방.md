# 대표님 지시: 「우리 동네 반려동물」 테마 방 (11-25 밤)

- 누가: 대표님 (음성 대화 → 본부)
- 상태: 작업 목록에 올림 — 진행 예정 (다른 방은 단메뉴, 이 방은 여러 칸이 든 묶음이라 큰 편)

## 무엇을
반려동물 키우는 집을 위한 한 화면(생활 도구 한 칸 + 필요하면 홈 카드). 흩어진 자료를 테마식으로 몰아서 보여 준다.

1. 맨 위: **지금 문 연 동물병원** (밤·주말 특히) — 가장 가까운 곳 크게 + 전화·길안내
2. 칸 나누기: 동물병원 · 미용 · 호텔(위탁) · 용품점 · 동물약국
3. 지도 ↔ 목록 (다른 기능과 같은 틀)
4. 뒤에 붙일 것: 산책하기 좋은 공원, 반려동물 동반 카페

## 자료 (활용신청 완료 11-25)
- 지방행정 인허가: 동물병원(animal_hospitals) · 동물미용업(pet_grooming) · 동물위탁관리업(animal_boarding) — 전화·영업상태·좌표(EPSG:5174)
- 소상공인 상가정보: 동물병원(M11101) · 애완동물/용품 소매(G22001)
- 영업시간은 공공자료에 없음 → 「지금 문 연」은 카카오 실시간 조회(저장 안 함) 또는 사장님 등록으로
- 추가 신청 후보: 동물약국(15155272)
