# 본부 → 반려동물 방: 반려동물 정보에 유튜브 영상 (대표님 11-26, 작업 목록 — 대표님 「시작해」 뒤 진행)

## 대표님 말씀
- 「남의 자료지만 재미있고 활성(이용)에 도움될 듯」 — 강형욱 훈련사 채널 영상 같은 것을 반려동물 정보에 제공.

## 만들 것
1. **공식 유튜브 플레이어로 앱 안 재생** (퍼가기). 영상 파일을 받거나 저장하지 않음 — 광고·조회수는 원래 채널 몫.
2. **주제별 묶음**: 산책 예절 · 배변 훈련 · 분리불안 · 짖음 · 고양이 화장실 · 노견 돌보기 등.
3. **채널 몇 곳을 정해 새 영상 매일 자동**: 채널 새 영상 목록(RSS, 열쇠 없이)으로 모으기 → web/data/pet/videos.json (수집기 하루 1번).
4. **우리 아이와 잇기**: 등록한 아이(종·나이)에 맞는 주제를 먼저 (예: 노견 → 노견 돌보기).
5. 퍼가기 막힌 영상은 「유튜브에서 보기」로 넘김.

## 지킬 것
- 특정인 이름을 앞세우지 않기: 「○○ 추천」처럼 보이면 안 됨. 「추천 영상 · 출처: ○○ 채널」 정도만.
- 한 채널만 넣지 말고 훈련사·수의사 채널 2~3곳 섞기 (채널 목록은 대표님과 정하기).
- 영상 제목·썸네일은 유튜브가 주는 그대로, 고쳐 쓰지 않기.
