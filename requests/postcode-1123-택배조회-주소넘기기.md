# 택배·우편 (postcode) — 본부 요청 · 작업판 0.3.0

## 1. 생활 도구 이름 「우편번호」 → 「택배·우편」 (확인만)
- feature.dart 의 name 을 「택배·우편」으로 바꿨습니다. 등록부·생활 도구 칸이 name 을 그대로 쓰면 따로 할 일은 없습니다.
- 폴더·id 는 처음 그대로 `postcode` 입니다.

## 2. 택배 조회 열쇠 (대표님 결정 뒤) — 급하지 않음
- 지금은 열쇠 없이 「택배사 조회 화면 열기」로만 돌아갑니다 (목록 저장·완료 7일 뒤 정리는 됨).
- 단계 표시(집하→이동 중→배송 출발→완료)·현재 위치는 화면 코드가 이미 있고(Parcel.stage/where), 조회 서비스만 붙이면 됩니다.
- 대표님이 서비스를 정하시면 깃허브 비밀 이름 하나(예: `PARCEL_KEY`)와 `lib/core/keys.dart` 한 줄 부탁드립니다.
- 공공데이터 「우정사업본부_우체국 종적 조회」(우체국 등기·소포, 무료·자동 승인)를 `DATA_GO_KR_KEY` 에 활용신청해 주시면 우체국택배는 먼저 붙이겠습니다. 다만 주소가 http(openapi.epost.go.kr)라 앱에서 부르려면 안드로이드 평문 통신 허용(이 주소만)이 필요합니다.

## 3. 배송 출발·완료 알림 (2 다음)
- 알림은 앱이 꺼져 있어도 와야 해서 서버(정해진 시간마다 조회)와 파이어베이스 푸시가 필요합니다. 공통 푸시가 생기면 그 틀을 쓰겠습니다.

## 4. 검색 화면 → 앱으로 주소 넘기기 (있으면 좋음)
- 지금은 web/postcode.html 의 「우리동네에 저장」이 클립보드에 `[우리동네 주소] {…}` 를 담고, 앱이 돌아올 때 읽습니다.
- 앱 안 웹뷰(webview_flutter)나 앱 열기 주소(kr.designfeel.dongne://…)가 생기면 클립보드 없이 바로 넘기도록 바꾸겠습니다.
