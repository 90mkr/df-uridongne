# 주유소: 오피넷 열쇠 + 가격 하루 3번 갱신

- 보낸 방: 우리동네 주유소 방
- 작업판 버전: gas 0.1.0
- 급함: 보통 (화면은 다 됐고, 이 두 가지가 들어가야 실제 가격이 뜸)

## 1. 깃허브 비밀 `OPINET_KEY`
- 오피넷 무료 API 열쇠는 아직 없음 (공공데이터 목록에도 「별도 신청」). 대표님이 오피넷 로그인 → 오픈 API → 인증키 발급으로 받으셔야 함.
- 받으면 깃허브 비밀 `OPINET_KEY` 에 넣어 주세요. 자동 제작에는 이미 이 이름으로 연결돼 있어 따로 고칠 곳 없음.
- 앱 화면은 열쇠를 쓰지 않습니다 (모아 둔 파일만 읽음). 열쇠는 `collector/features/gas.py` 만 씀.

## 2. 주유소 가격만 하루 3번 모으기
- 지금 「앱 제작」은 매주 월요일에만 모아서, 기름값으로는 너무 오래됨 (가격은 하루에도 바뀜).
- 부탁: 주유소만 하루 3번(한국 시각 대략 07:40 · 12:40 · 18:40) `python3 -u collector/features/gas.py` 를 돌리고
  `web/data/gas/` 만 커밋 → 크롬 미리보기(Pages)에 다시 게시.
  - 예: `앱 제작` 에 cron 3개를 더 넣고, 그 시각엔 `collect.py`(카카오 업체) 는 건너뛰고 gas.py 만 돌리는 갈래.
  - 또는 「주유소 가격」 워크플로 하나를 따로 (concurrency 는 pages 그대로).
- 조회량: 송도 한 번에 반경 검색 9곳×4종 = 36회 + 처음 보는 주유소 상세(첫날만 수십 회, 이후 월요일 아침에만). 무료 한도 안.
- gas.py 는 환경 변수 `AREAS`(쉼표 동네 id)도 따릅니다. 비우면 ready·collect 인 동네 전부.

## 추가 (21:15)
- 오피넷 열쇠 발급 완료 — 무료 열쇠는 **하루 300회**. gas.py 는 한 번 실행에 최대 90회(GAS_MAX_CALLS)로 묶어 둠 → 하루 3번까지 안전.
- 열쇠는 대표님이 깃허브 비밀 `OPINET_KEY` 에 직접 넣으시는 중 (주유소 방이 안내).
