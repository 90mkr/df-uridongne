# 홈: 스크롤해서 내려갔다가 위로 잘 안 올라감 (대표님 11-28 14:17 — 지하철 노선도 확대 방이 대신 올림)

- 대상: 본부 (lib/core/home.dart) · 필요하면 룰렛 방(lib/features/roulette)
- 급함: 높음 — 대표님 말씀: 「지금 메인에서 스크롤 시 위로 안 올라감. 룰렛 때문인지」
- 대표님 화면: 「현위치」 기준, 룰렛 카드·생활 바로가기까지 내려온 상태에서 위로 다시 안 올라감

## 살펴본 것 (휴대폰에서 직접 돌려 보지는 못함 — 코드만 읽고 낸 짐작)
1. **가장 의심: 홈 목록이 「보이는 것만 만드는」 ListView** (`home.dart` 144줄쯤 `ListView(key: ValueKey('home$gen'), …)`)
   - 화면 밖으로 나간 카드는 버려졌다가, 위로 올릴 때 다시 만들어짐.
   - 카드 대부분이 자료를 받는 동안 높이 0(`SizedBox()`)이었다가 받은 뒤 커짐 → 위로 올리는 도중 위쪽 카드 높이가 0 → 커짐으로 바뀌면서 화면이 밀려, 올려도 제자리처럼 느껴질 수 있음.
   - 고치는 방법(둘 중 하나): ① `ListView` 에 `cacheExtent: 6000` 쯤 넉넉히 → 카드를 버리지 않게, ② `SingleChildScrollView + Column` 으로 바꿔 전부 한 번에 만들기 (카드 수가 많지 않아 부담 적음, `RefreshIndicator` 는 `physics: AlwaysScrollableScrollPhysics()` 그대로).
2. 「현위치」 기준일 때 `baseTick` 이 오르면(300m 이동·기준 바꿈) 가상 단지 id(`here_위도_경도`)가 바뀌어 카드 열쇠(`'${f.id}${fc.id}$gen'`)가 전부 바뀜 → 모든 카드가 새로 만들어지며 다시 높이 0부터 → 1번과 겹치면 더 심해짐. 열쇠에서 `fc.id` 대신 「집/현위치」 구분만 쓰는 것도 검토.
3. 룰렛 카드 자체(`roulette/feature.dart` 홈 카드)는 `InkWell` 누르기뿐이고 손가락 끌기를 가로채는 곳은 못 찾음 (원판은 `IgnorePointer`). 다만 원판이 카드 위로 튀어나오게 `Stack(clipBehavior: Clip.none)` + 위 여백으로 그려져 있음 — 1번을 고친 뒤에도 남으면 이쪽을 볼 것.

## 확인 방법
홈에서 맨 아래까지 내렸다가 한 번에 위로 쓸어 올려 맨 위까지 걸림 없이 올라오는지 (집 기준·현위치 기준 둘 다, 휴대폰 설치 파일로).
