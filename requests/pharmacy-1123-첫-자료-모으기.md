# 약국 자료 첫 모으기 · 기능 자료만 따로 도는 실행

- 기능: 지금 문 연 약국 (작업판 0.1.0)
- 급함: 보통 (자료가 없으면 앱 카드에 「약국 자료를 모으고 있어요」만 보임)

## 1. 첫 자료 모으기
`collector/features/pharmacy.py` 를 올렸습니다 (국립중앙의료원 약국·소아청소년과·응급실 → `web/data/pharmacy/`).
지금 돌고 있는 수동 실행(#10)은 올리기 전 코드라 약국이 빠져 있습니다.
#10 이 끝난 뒤 「앱 제작」을 한 번 더 수동 실행해 주세요 (동네 칸은 `songdo` 정도로 짧게).

필요한 공공데이터 활용 신청 (DATA_GO_KR_KEY 한 열쇠로):
- 국립중앙의료원_전국 약국 정보 조회 서비스
- 국립중앙의료원_전국 병·의원 찾기 서비스
- 국립중앙의료원_전국 응급의료기관 정보 조회 서비스
- (있으면) 한국천문연구원_특일 정보 — 없으면 공휴일 기본 목록으로 돕니다

## 2. 제안: 기능 자료만 도는 가벼운 실행
지금은 기능 자료(`collector/features/*.py`)가 카카오 업체 모으기(최대 4시간) 뒤에만 돌고,
수동 실행이 기다리는 동안 다른 방이 올리면 대기 중인 실행이 취소됩니다.
`workflow_dispatch` 입력에 「기능 자료만」(예: `only_features: true` → collect.py 건너뜀)을 두면
기능 방들이 자료를 금방 확인할 수 있습니다.
