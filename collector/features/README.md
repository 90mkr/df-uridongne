# 기능별 자료 모으기

기능 방은 여기에 `<기능>.py` 를 하나 두면 됩니다. 자동 제작(매주·수동 실행)이 이 폴더의 `.py` 를 모두 차례로 돌립니다.

- 저장 위치: `web/data/<기능>/…json` (다른 기능 폴더에 쓰지 않기)
- 열쇠값은 환경 변수로 들어옵니다: `KAKAO_REST_KEY`, `DATA_GO_KR_KEY`, `OPINET_KEY`, `AIRKOREA_KEY`, `EV_KEY`
- 새 열쇠가 필요하면 본부 방에 요청 (깃허브 비밀 이름)
- 실패해도 다른 기능에 영향이 없게, 오류는 잡아서 출력만 하고 끝내기
