# 본부 → 모든 기능 방: 「내 정보·기록」은 로그인한 사람만, 서버에 저장 (대표님 11-26)

## 원칙
- **내 정보·기록을 적는 곳만** 저장할 때 로그인을 요청하고, 로그인한 사람만 저장합니다.
  - 예: 반려동물 우리 아이 등록, 몸무게 기록, 기념일, 내 번호(로또) 같은 「내 것」.
- 우리 단지 고르기, 홈 편집, 보기만 하는 기능은 **로그인 없이** 지금처럼 씁니다(이 휴대폰 prefs).
- 로그인한 사람의 기록은 파이어베이스에 저장됩니다. 앱을 다시 깔거나 휴대폰을 바꿔도 로그인하면 그대로 나옵니다.

## 쓰는 법 — `lib/core/mydata.dart` (본부가 만듦, 기능 방은 고치지 말 것)
```dart
import '../../core/mydata.dart';

// 저장: 로그인 안 했으면 「로그인하면 저장돼요」 안내 → 로그인 창 → 로그인하면 저장. 저장되면 true
if (await saveMine(context, 'pet.kids', kids.map((k) => k.toJson()).toList(), why: '우리 아이 정보')) {
  toast(context, '저장했어요');
}

// 불러오기: 로그인 안 했으면 null (서버를 못 닿으면 이 휴대폰에 남은 마지막 값)
final v = await loadMine('pet.kids');            // List / Map / 문자 … (저장한 모양 그대로)

// 지우기
await deleteMine('pet.kids');

// 로그인만 먼저 확인하고 싶을 때 (예: 「기록 추가」 단추 누르자마자)
if (!await needLogin(context, why: '몸무게 기록')) return;

// 로그인·로그아웃하면 화면을 다시 불러오기
ValueListenableBuilder(valueListenable: authTick, builder: (_, __, ___) => …);   // core/fb.dart
```
- 키 이름: **「기능이름.무엇」** (예: `pet.kids`, `pet.weight`, `anniv.list`, `lotto.mine`). 다른 기능 키는 쓰지 않기.
- 값: JSON 으로 바꿀 수 있는 것(Map·List·문자·숫자·참거짓). 한 키에 400KB 까지. **사진은 넣지 말 것**(사진이 필요하면 본부에 요청).
- 자주 바뀌는 기록(몸무게 등)은 한 키에 목록으로 모아 저장하세요. 저장할 때마다 전체를 다시 저장합니다.

## 지금 이 휴대폰에만 저장된 기록이 있다면
- 로그인 전 기록이 prefs 에 있는 기능은, 로그인 후 처음 열 때 한 번 `saveMine` 으로 옮기고 prefs 를 비워 주세요.
  (로그인을 안 한 사람에게는 기존 기록을 지우지 말고 「로그인하면 저장돼요」만 안내)

## 서버 칸·규칙 (본부 처리)
- 칸: `dn_my/{로그인 번호}/d/{키}` — 필드 `j`(JSON 문자), `at`(시각).
- 규칙: 로그인한 본인만 읽고 쓰기 (firestore.dongne.rules). 대표님이 규칙을 게시해야 실제 저장이 됩니다.
