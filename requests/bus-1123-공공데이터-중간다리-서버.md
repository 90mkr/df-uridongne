# 공공데이터 「중간 다리」 서버 (급함 — 모든 실시간 기능 공용)

- 요청 방: 단지 앞 버스 (작업판 0.2.0)
- 영향: 버스 · 약국 · 주차장 · 충전소 · 날씨 등 앱이 공공데이터를 바로 부르는 모든 기능

## 문제
1. **크롬 미리보기에서 안 뜸** — apis.data.go.kr 이 다른 홈페이지 요청을 허락하지 않아(CORS) github.io 미리보기에서 실시간 자료가 버려짐.
2. **열쇠가 드러남** — `--dart-define` 으로 넣은 DATA_GO_KR_KEY 가 공개 미리보기 JS·설치 파일 안에 그대로 들어감. 남이 꺼내 하루 한도(개발 계정 1만 회)를 다 쓸 수 있음. 정식 출시 전 반드시 막아야 함.
3. **한도 낭비** — 이용자마다 같은 정류장을 따로 부름.

## 제안
열쇠를 서버에만 두고 대신 불러 주는 다리 하나 (클라우드플레어 Workers 무료 또는 콕플 파이어베이스 Functions).
- 주소 예: `https://<다리>/dg/<경로>?<원래 질문>` → 서버가 `serviceKey` 를 붙여 `https://apis.data.go.kr/<경로>` 를 부르고 그대로 돌려줌
- 응답에 `Access-Control-Allow-Origin: *`
- 같은 주소는 30초 묶어 두기(캐시) — 실시간 아닌 노선·정류장은 12시간
- 허용 경로만 통과 (1613000/…, B552657/… 등), 남이 열쇠 대신 쓰지 못하게 앱 이름 머리값 정도 확인
- `lib/core/keys.dart` 에 `kDataProxy` (예: `String.fromEnvironment('DATA_PROXY')`) 를 두고, 값이 있으면 기능들이 다리를 쓰고 앱에서는 DATA_GO_KR_KEY 를 빼기

## 버스 쪽 준비
`kDataProxy` 가 생기면 버스는 `lib/features/bus/data.dart` 의 `_call` 한 곳만 바꾸면 됨 — 본부가 이름을 정해 주시면 바로 맞춥니다.
