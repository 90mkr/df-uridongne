# 대표님 지시: 커뮤니티 방을 「단체 홈페이지」처럼 + 일자리 마당 (11-25 밤)

- 누가: 대표님 (음성 대화 → 본부)
- 상태: 작업 목록에 올림 — 진행 예정

## 1. 커뮤니티 첫 화면 = 게시판 모음(포털식)
들어가면 글 몇 개짜리 한 게시판이 아니라, 단체 홈페이지 메인처럼 **게시판별 최근 글 묶음이 아래로 쭉** 나온다.
- 예: 공지·소식 / 나눔터 / 자유게시판 / 업체 추천 / 분실물 / **일자리 마당** …
- 묶음마다 제목 3~5줄(제목 위주, 목록엔 사진 없음 — 사진은 글 안에서만), 「더보기 ›」로 그 게시판 전체
- 지금 만든 「우리 단지 · 우리 동네」 두 층은 그대로 — 위 단추로 바꾸면 묶음들이 그 범위로 바뀜
- 저장은 지금처럼 한 곳(dn_posts)에 분류(cat)로 나눠도 화면은 게시판 여러 개처럼 보이게 하면 됨 (본부 의견: 제목 위주라 문제 없음)

## 2. 일자리 마당 (워크넷 → 고용24 채용정보)
- 범위: **구(시군구) 단위** — 송도면 인천 연수구 전체 공고, 최신순 (대표님 결정)
- 줄마다: 공고 제목 · 회사 · 급여 · 마감일(작은 알약), 누르면 고용24 원문
- 화면은 요기콕 디자인으로 직접 (자료만 받아 옴)
- 필요: 고용24(구 워크넷) 오픈 API 인증키 — 대표님 신청 대기

## 3. 게시판별 알림 고르기 (대표님 덧붙임 22:22)
- 내 정보 → 알림 설정에 게시판마다 체크: 공지·소식 / 나눔터 / 자유 / 업체 추천 / 분실물 / 일자리 마당 (단지·동네 따로)
- 기본값: 공지·소식만 켜짐, 나머지는 꺼짐 (알림 폭탄 막기)
- 내 글에 댓글 달림은 따로 한 줄(기본 켜짐)
- 일자리 마당은 「새 공고 하루 한 번 모아서」 처럼 묶어 보내기
- 방식: 휴대폰 알림(FCM) 주제 구독 — 게시판·범위별 주제(예: a_<동네>_share), 서버 쪽은 새 글이 올라올 때 그 주제로 보냄

## 4. 우리 동네 지원금·혜택 (대표님 덧붙임 22:29)
- 커뮤니티 방 안에 카드 하나(첫 화면 배너 같은 큰 카드) → 누르면 게시판 목록처럼 **우리 구(시군구) 혜택 제목이 쭉**
- 줄을 누르면: 지원 대상 · 금액(지원 내용) · 신청 방법·기한 · 문의처 · 원문(정부24) 바로가기
- 「나에게 맞는 것만」: 나이대·자녀 유무·어르신 여부를 직접 고르게 해서 「해당될 수 있는 혜택」으로 거르기 (본인인증 없이 — 정부24처럼 딱 집어 주지는 못한다고 안내)
- 자료: 행정안전부 「공공서비스(혜택) 정보」 오픈API (data.go.kr, 전국 약 1만 건, 소관기관·지역 코드) — 활용신청 필요
- 자주 바뀌니 서버에서 매일 받아 동네(시군구)별 파일로 (앱 업데이트 없이 반영)

## 참고 (대표님 22:35): 앱 방향
- 기능을 많이 담되 각자 필요한 것만 골라 쓰는 앱 — 처음 깐 사람에겐 동네에서 많이 쓰는 몇 가지만 기본으로 켜고 나머지는 「더 담기」에서 고르게(홈 편집과 연결)
