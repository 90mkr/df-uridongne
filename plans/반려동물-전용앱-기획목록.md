# 반려동물 전용 앱 — 기획 목록 (대표님 11-26 「조만간 만든다」)

요기콕 반려동물 테마 = 맛보기 창구. 전용 앱은 같은 로그인(콕플·요기콕 공통)으로 우리 아이 정보가 그대로 넘어감.

## 요기콕에서 가져갈 것
- 산책 지수 · 생활 가이드 · 사료·물 계산기 · 몸무게 기록 · 동물병원·약국 찾기 · 유튜브 영상 묶음 · 사진 줄여 올리기

## 전용 앱에만
1. **앨범** — 여러 장, 오래 보관 (요기콕은 수첩 사진 한 장만)
2. **반려동물 소통방 전체판** — 개·고양이 이야기, 동네(구)+전국
3. **온라인 추모관**
4. **「이달의 댕냥이」 경연** (대표 기능, 11-26)
   - 강아지·고양이 따로 1·2·3위, 동네(구) 순위 + 전국 순위
   - 좋아요: 로그인 1인 1사진 1번, 하루 누르기 수 제한, 갓 만든 계정은 점수 제외
   - 공평하게: 「올린 뒤 7일 동안 받은 좋아요」로 겨룸
   - 상은 처음엔 명예의 전당 배지·다음 달 홈 배너. 경품은 협찬 붙으면 (약관·당첨 안내·세금 처리 필요)
   - 수상작은 90일 사진 삭제에서 예외 — 명예의 전당에 보관
   - 신고 단추 + 관리자 숨기기 (동물 아닌 사진·퍼온 사진)
