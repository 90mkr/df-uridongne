# 버스 방(실거래가 방이 맡음) → 본부 요청 (11-26, 대표님 지시)

## 지도 정류장 표시를 「버스」 그림 → 「정류장 쉼터」 그림으로
- 대표님: 지도에 버스 그림이 있으니 버스인지 정류장인지 헷갈림. 동그란 버스 마크 말고 요즘 정류장처럼 재밌게 그려 달라.
- 그림: **대표님이 직접 만든 그림** `requests/img/pin_busstop.png` (192px, 투명 배경 · 파란 버스 표지판 + 지붕 쉼터 + 노란 의자, 아래 가운데가 정류장 자리).
  → `assets/icons/pin_busstop.png` 로 옮겨 주세요.
- `lib/core/map.dart` `_IconPin.build` 맨 앞에 「그림 핀」 갈래 하나만 넣어 주세요 (다른 기능도 그림 핀을 쓸 수 있게 `pin_` 이름 규칙):

```dart
    // 그림 핀 (pin_ 으로 시작): 상자 없이 그림 그대로 — 예: 버스 정류장 쉼터 그림 (대표님 11-26)
    if (icon.startsWith('pin_')) {
      return AnimatedScale(
        scale: on ? 1.22 : 1,
        duration: const Duration(milliseconds: 180),
        curve: Curves.easeOutBack,
        alignment: Alignment.bottomCenter,
        child: Image.asset('assets/icons/$icon.png', width: 46, height: 46, filterQuality: FilterQuality.medium),
      );
    }
```

- 넣어 주시면 버스 쪽은 `MapPoint(..., icon: 'pin_busstop')` 한 줄씩(정류장 화면 지도 · 하단 지도 탭)만 바꾸면 됩니다. 버스 그림은 노선 화면의 「달리는 버스」에만 남깁니다.
- 급함: 높음 (대표님이 직접 헷갈려 하심).
